# Shorts Script Reviewer (free skill)

The reviewer from my "AI made 30 Shorts while I slept" factory:
an 8-question yes/no checklist + fact check, and the planted-mistake test that checks the checker.

## Install
- **Claude Code:** copy this folder to `~/.claude/skills/shorts-script-reviewer/`, then ask: "review this script".
- **Hermes Agent:** copy it to `~/.hermes/skills/shorts-script-reviewer/`.
- **No agent?** Open `references/prompts.md` and paste the prompts into ChatGPT, Claude or Gemini.

## Files
- `SKILL.md` - the rulebook: checklist, verdicts, rewrite loop, planted-mistake test.
- `references/prompts.md` - copy-paste prompts.
